How it works

  1. Stream reads from disk with memory-mapped, chunked I/O.
  2. Seed each read against a BWT/FM-index (Cython) — unrelated reads never reach the GPU.
  3. Align thousands of read/window pairs in parallel (CUDA kernel, or Numba CPU fallback).
  4. Trace back survivors on CPU, verify the GPU score, extract SNPs & indels.
  5. Report a VCF file plus accuracy vs. truth (for simulated data).
