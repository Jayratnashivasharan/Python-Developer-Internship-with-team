About gpualign

gpualign is a high-throughput DNA read aligner. It runs an affine-gap Smith-Waterman kernel on the GPU directly from Python (Numba CUDA), with an automatic multi-core CPU fallback that uses the identical algorithm.

Pipeline

  • I/O — memory-mapped FASTA/FASTQ, streamed in chunks (no RAM limit on read files).
  • Pre-filter — BWT/FM-index seeding in Cython; reads without a consistent locus are dropped.
  • Alignment — one GPU thread per read/window pair; pinned memory pool and async streams.
  • Traceback & verification — CPU traceback on survivors; GPU score is re-checked.
  • Variants — pileup caller producing SNPs and indels in VCF 4.2.

Limits

  • The reference index is built in memory — practical up to a few hundred Mbp.
  • Reads longer than {{ sys.max_query }} bp are skipped (kernel local-memory limit).
  • Variant calling is a simple pileup model, intended for validation and demonstration.
