API

WebSocket /ws/generate — send JSON, receive streamed token frames:

// client → server
{"prompt": "Hello", "max_new_tokens": 64, "temperature": 0.8, "top_k": 40}
// server → client (repeated)
{"type": "token", "token_id": 12, "text": "a"}
// server → client (final)
{"type": "done", "finish_reason": "length", "ttft_ms": 14.2, "tokens": 64}

HTTP: POST /v1/generate · POST /v1/generate/stream (SSE) · GET /metrics · GET /health · interactive docs at /docs
